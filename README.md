# Website Traffic Analysis

## Objective
Analyze website traffic performance by source to understand volume, engagement, and conversion behavior.

## Dataset
Source: Kaggle  
Description: Session-level website traffic data containing engagement and conversion metrics.

## Tools Used
- SQL Server (data exploration and aggregation)
- Excel (pivot tables, charts, insights)

## Approach
1. Explored and validated dataset structure
2. Created aggregated views in SQL
3. Connected Excel directly to SQL Server
4. Built pivot tables and visualizations
5. Summarized insights and documented limitations

## Key Insights
- Organic traffic drives the highest session volume.
- Conversion rates are uniformly high across sources.
- Bounce rates show minimal variation by source.

## Data Limitations
- Metrics are pre-aggregated, limiting weighted KPI calculations.
- No time dimension available for trend analysis.

## Files
- `AllViews.sql`: SQL queries and views
- `Executive Traffic Summary.xlsx`: Final analysis and visuals
